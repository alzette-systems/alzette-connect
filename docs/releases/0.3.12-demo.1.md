# Alzette Connect 0.3.12-demo.1 — Windows candidate

This is an unsigned Windows x64 acceptance build, not a signed production
release. It enables the Windows ChatGPT candidate and Claude Desktop adapter.

## Changes

- Discover and launch Windows Store ChatGPT, including its Codex workspace,
  with a scoped Responses connection and reversible model configuration.
- Discover and launch Windows Claude Desktop in third-party mode, with
  assigned company models mapped to its model slots through the Messages API.
- Store temporary Claude helper credentials in Windows Credential Manager,
  supervise application processes, and restore managed profiles on disconnect.
- Refresh model endpoint health in Connect without replacing an active
  application's credential for health-only changes.
- Include reproducible Windows QA fixtures and retained ChatGPT, Claude Code
  and Cowork evidence.
- Update the frontend source-map dependency to its patched 1.2.2 version.

## Validation and scope

The source passes frontend tests, Go tests, race checks, vet and packaging
checks. The downloadable installer is built and tested on the Windows CI
runner from the release's exact source commit.

Prior native Windows acceptance covers ChatGPT Responses and tool round trips,
Claude Code text/tools, and Cowork's Linux workspace tools, Python-generated
Excel files, model switching and cleanup. Live Claude acceptance used an
isolated Alzette gateway with assigned DeepSeek routes; it does not certify a
public gateway deployment. See [the acceptance matrix](../DESKTOP_PARITY.md)
and [Claude evidence](../evidence/windows-claude-deepseek-2026-10-06/README.md).

Claude requires a gateway deployment with the qualified Messages adapter and
assigned model routes. Browser tools, broader Office automation and Microsoft
Copilot integration are outside this candidate's qualified scope.

The installer and application are unsigned. Publisher signing and production
release qualification remain separate from this candidate build.

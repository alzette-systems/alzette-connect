# Alzette Connect 0.3.12-demo.2 — Windows candidate

This unsigned Windows x64 acceptance build supersedes `0.3.12-demo.1`.
It contains the [same Windows integrations](0.3.12-demo.1.md) and builds the
desktop executable with Wails' production tag and the Windows GUI subsystem.
Connect opens without a separate debug console.

The exact installer passed Windows VM upgrade, reinstall, native startup,
installed credential-helper and uninstall checks. Source CI passed on Windows,
macOS and Linux; checksum and build provenance verification also passed.
See the [installer acceptance evidence](../evidence/windows-release-0.3.12-demo.2-2026-10-06/README.md).

ChatGPT and Claude Desktop are enabled. The prior acceptance evidence covers
Claude Code tools, Cowork Linux tools, Excel generation and model switching
against an isolated Alzette gateway. A compatible Messages gateway deployment
and assigned routes are required for live Claude use.

The application and installer are unsigned test artifacts. This candidate does
not add Microsoft Copilot integration or claim production signing approval.
